# StudySync — Student Planner SaaS

A colourful, responsive student planner built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive dashboard with colourful stat cards
- Create, edit, complete, delete, search, and filter tasks
- Labels for STUDY, EXAM, ASSIGNMENT, PROJECT, PERSONAL, and EVENT
- Priority labels and due dates
- Exam and deadline countdowns
- Focus timer with 25, 15, and 5-minute presets
- Progress analytics and completion percentage
- Dark mode
- Browser localStorage saves tasks and deadlines

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser. No installation is needed.

## Publish with GitHub Pages
1. Open the repository on GitHub and select **Settings → Pages**.
2. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
3. Wait for publishing. GitHub will show the site URL in Pages settings.

## Project structure
- `index.html` — page structure
- `css/style.css` — styling and responsive layout
- `js/app.js` — task, deadline, timer, and theme interactions
- `TODO.md` — project checklist

## SaaS note
This is a front-end prototype. Data is stored in the current browser only. Accounts, secure cloud sync, collaboration, reminders, and payments require a backend and authentication.
